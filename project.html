PERFORMANCE AUTOMOTIVE COMPUTING

Our Project

PACE is developing a real-time computing and telemetry system for Northern Arizona University's Formula SAE vehicle. The system will collect vehicle data, process that information, and make important performance data available to the driver and team.

High-level requirements

Project Goals

By the end of this year, we have three main goals we want to achieve:

  • Implementation of custom CAN bus protocol library using ECU documentation.
  • Deployment of a docker container on a Raspberry Pi to pull data from the ECU.
  • Formulation of a tablet dashboard display installable to the vehicle using PyQT framework, pulling data from minicomputer at a latency of less than 20ms. Displays RPM, MPH, fuel, engine temperature, oil temp.

Stretch Goals

Some stretch goals we hope to achieve for this project are as follows:

  • Build network software for telemetry systems to transmit and receive live sensor data for engineers in the pit.
  • Write a C++ library for GPS processing and tracking, and transmit data to remote radio modules for lap analysis through custom lap analysis software.
  • Safety system - Sensor polling module to emergency stop the engine if detected internal temperature can damage components.

THE PROPOSED SOLUTION

Connecting to the Car

The PACE system is designed to address this problem by providing a real-time computing and telemetry solution for the Formula SAE vehicle. The system will interface with the car's CAN bus, collect and process vehicle data, and display important information to the driver through a dashboard interface.

THE PRODUCT

From Data to Decisions

The finished PACE system will provide the Formula SAE team with a powerful tool for monitoring and optimizing vehicle performance. By collecting and analyzing real-time data, the team can make informed decisions that improve the car's performance on the track. The system will also enhance the driver's experience by providing them with critical information about the car's status and performance.

PROJECT GOALS

The PACE system is being developed around several core requirements that define what the final system should accomplish.

SYSTEM OVERVIEW

Envisioned Solution

The PACE system will connect several hardware and software components to move information from the Formula SAE vehicle to the driver and team. Vehicle data will be collected from the ECU through the CAN bus, processed by the onboard computing system, and presented through a real-time dashboard.
