TOOLS & TECHNOLOGIES

Building PACE

PACE combines hardware, software, communication protocols, and development tools to collect, process, and display data from the Formula SAE vehicle.

LANGUAGE

C++

Used to develop performance-focused software for processing vehicle and telemetry data.

COMMUNICATION

CAN Bus

Allows the PACE system to communicate with the vehicle's ECU and access real-time vehicle data.

HARDWARE

Raspberry Pi

Serves as the onboard computing platform responsible for collecting and processing vehicle data.

INTERFACE

PyQt

Used to create the graphical dashboard that displays important vehicle information to the driver.

DEVELOPMENT

GitHub

Used for version control, collaboration, and managing the project's software codebase.
